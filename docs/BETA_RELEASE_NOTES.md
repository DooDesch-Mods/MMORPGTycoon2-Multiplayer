# Early Beta 26 - Shared editing

> 🛟 **Need help or found a bug?** Get support at [support.doodesch.de/multiplayer](https://support.doodesch.de/multiplayer).

Build together with shared selection moves, scenery and building copies, and scenery groups, including Undo and Redo.

- Fixed desyncs when only one player opens building info.
- Reduced stalls during Group edits.
- Added regression coverage for shared edits and their history.

Both players need Multiplayer Beta 26 and **MT2 Mod Framework Runtime 0.5.1**. Close the game, update both mods in Vortex, deploy, then start through Steam.

This is an early beta. Modular construction, dungeons and generic management commands are not yet available in the new shared simulation. Start with a small world. Online play with separate Steam accounts, large worlds and four players still need acceptance testing.
