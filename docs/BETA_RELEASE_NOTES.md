Private Windows x64 tester beta.

> 🛟 **Need help or found a bug?** Get support at [support.doodesch.de/multiplayer](https://support.doodesch.de/multiplayer).

Download the ZIP and checksum, verify the hash, and extract the full ZIP outside the game installation. Start Steam and run `MT2MP-Start.exe`. Keep its `_internal` folder beside the starter. Each player needs a legal copy of the supported game version. See the included `README.txt` and repository `docs/BETA.md`.

This package uses an isolated test runtime. The intended drop-in installation remains in development. Separate-account Steam joining, world transfer, complete gameplay, all object families, Undo/Redo, large worlds and four-player sessions are not fully accepted.

CI builds and checks source and package contents. It does not launch the game or prove online gameplay. Game files, original Steam libraries, saves and personal settings are not included. Project and third-party license notices are included.
