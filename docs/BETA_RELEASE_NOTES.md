# Shared developer control

> 🛟 **Need help or found a bug?** Get support at [support.doodesch.de/multiplayer](https://support.doodesch.de/multiplayer).

## Highlights

- **Assign developers from the Client.** The original Staff control now sends Starting Points worker allocation through the Host.
- **See the same development activity.** Active developer counts, project status and individual activities match the Host in the native Development window.
- **Follow real project progress.** The Host's developers do the work; both players see the same code and research progress.

## Install and play

1. Close the game and extract the release ZIP. Copy `WSOCK32.dll`, `MT2_Multiplayer.dll` and `mt2mp_ui` into the folder containing `MT2.exe`.
2. Both players use this beta and launch through Steam. The Host opens a lobby; the Client opens its public lobby row to join.
3. The Host creates or opens a small world, or selects a save and presses **Load world and start**. Wait for both players to reach the ready state before building.

**Updating from beta.2?** If its files were copied into the game folder, follow the [upgrade steps](https://github.com/DooDesch/MMORPGTycoon2-Multiplayer/blob/main/docs/BETA.md#migrate-a-legacy-proxy-copied-into-the-game-directory) first. Keep your saves and existing test folders.

Undo/Redo, complete action coverage, four players and large worlds remain open. The shared online test with separate Steam accounts is still manual.
