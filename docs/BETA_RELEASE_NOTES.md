# Early Beta 27 - Shared management and smoother saves

> 🛟 **Need help or found a bug?** Get support at [support.doodesch.de/multiplayer](https://support.doodesch.de/multiplayer).

Manage staff and advertising together, and keep building after a shared autosave.

- Added shared GameMaster hiring and firing, with matching staff and costs.
- Added shared advertising purchases and daily campaign effects.
- Added shared release-planner changes and budget allocation.
- Added shared Inn service prices and price-sync settings.
- Fixed dismissing a developer while they are working on construction.
- Fixed a client input lock that could remain after autosave.
- Fixed hangs during shared saves and cancelled character tasks, together with Framework 0.5.4.
- Fixed NPC and character simulation differences caused by each player's camera view.

Both players need **Multiplayer Beta 27** and **MT2 Mod Framework Runtime 0.5.5**. Close the game, update both mods in Vortex, deploy, then start through Steam.

This is an early beta for small-world testing. Some management actions, connected travel services, modular construction and dungeons remain incomplete. Separate-account online play, large worlds and four players still need acceptance testing.
