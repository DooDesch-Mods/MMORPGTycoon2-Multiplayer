MT2 Multiplayer - private test candidate
=======================================

This archive contains the current mod DLLs and native menu assets.
It is a prepared payload. The isolated Steam starter and acceptance across
two computers are still required. ready_for_manual_testing is false.

The legacy install.bat is excluded: copying the DLLs alone does not activate
the current co-op configuration completely. Do not copy this payload into
the Steam game directory as an installation package.

package.json lists the required game hash, payload sizes and SHA256 hashes.
Each player needs their own Steam copy of the game. Original game files,
personal saves and session data are excluded.

Targeted local checks exist for placement, movement, removal, shared time
and selected economy and NPC states. These checks do not establish complete
support for every game action or the cross-computer Steam connection.
