MT2 Multiplayer - private two-player test
=======================================

Experimental test build, not a complete co-op release. Targeted local tests
and creation of a real Steam lobby have passed. Joining, world transfer and
shared gameplay across two computers still require acceptance.

START ON BOTH COMPUTERS
1. Extract the same ZIP into a separate folder outside the game directory.
2. Start Steam with your own account. Both players must own MMORPG Tycoon 2.
3. Open MT2MP-Start.exe. If prompted, enter the folder containing MT2.exe.
4. Open the Multiplayer app on the in-game desktop.

HOST
1. Create and save a small world through New Game first.
2. Open the Multiplayer app and choose the friends lobby option.
3. Invite your friend. Joining by lobby ID is an alternative.
4. Select the world, load it and start the session after readiness is confirmed.

CLIENT
1. Open lobby search once before accepting a Steam invitation.
   Invitation handling immediately after a cold start is not yet verified.
2. Accept the invitation or enter the lobby ID to join.
3. Wait for the complete world transfer and loading acknowledgement.

Use a new small world for the first test. Check placement, movement, removal
and shared time. Pause after a session failure and retain the logs. Support
for all object types, undo/redo and simulation systems is incomplete. Large
saves and four-player sessions remain later tests.

DATA AND DIAGNOSTICS
The original installation stays unchanged. The starter creates a separate
copy under _SteamTest/_MPTest/host/game. Test saves stay under host/data.
Diagnostics are in host/diagnostics; game logs include host/game/mt2mp.log.
Exit the game normally. Preserve the test directory and its saves on updates.

Supported: Windows x64, game build 24993678. An unsupported MT2.exe hash is
rejected with a reason. package.json lists payload hashes and the game hash.
The starter includes Python; no separate Python installation is required.
Libraries include Python, PyInstaller, MinHook, Dear ImGui, SDL3 and Steam SDK.
Starter license notices are under licenses/.
